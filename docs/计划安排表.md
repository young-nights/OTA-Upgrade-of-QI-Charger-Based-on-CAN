# Qi 无线充电模块项目计划安排表

> 项目：基于 AT32F426 的 Qi 无线充电模块（CAN 通信 + OTA + 充电管理）
> 更新：2026-09-02

---

## 一、总体架构

```
┌──────────┐    CAN 250kbps    ┌──────────────────────────────┐
│  主控制器  │ ───────────────→ │  MCU (AT32F426)              │
│  (CCU)    │ ←─────────────── │  ├─ Bootloader (OTA)         │
│           │  0x18DA0D03/0D   │  ├─ APP (UDS + 充电控制)      │
└──────────┘                   │  ├─ QI 芯片 (I2C/SPI)        │
                               │  └─ SIT1145 (CAN 收发器)     │
                               └──────────────────────────────┘
```

**核心功能 7 大块**：

| # | 功能块 | 说明 | 优先级 |
|---|--------|------|--------|
| A | OTA 升级（A/B 双槽） | Boot + APP + 脚本，ECDSA 签名，trial boot 自动回滚 | P0 |
| B | SN 序列码存储 | Device Info 区读写，UDS DID 读写 | P1 |
| C | 夹臂检测与控制 | PA0 Hall 传感器检测 + 夹臂状态上报 | P1 |
| D | 低功耗管理 | MCU Sleep/Standby + SIT1145 Standby + 唤醒源配置 | P2 |
| E | QI 芯片 IAP 升级 | 通过 I2C/SPI 对 QI 芯片固件升级 | P1 |
| F | QI 充电信息通信协议 | QI 芯片状态/功率/温度/故障等数据采集与上报 | P1 |
| G | 充电启停控制 | 5V/12V Buck 控制 + QI 芯片启停 + 安全保护 | P1 |

## 十一、依赖关系

```
M4 (OTA 稳定) ──→ M5 (端到端 OTA) ──→ M6 (SN 产线)
                                      ↓
M7 (夹臂) ─────────────────────────→ M11 (集成测试)
M8 (QI 通信) ──→ M9 (QI IAP) ──────→ M11
M10 (低功耗) ───────────────────────→ M11
```

- M4 是当前阻塞点，所有后续依赖它
- M7（夹臂）和 M8（QI 通信）可并行开发
- M10（低功耗）依赖 M7/M8（需要知道哪些模块需要低功耗控制）
- M9（QI IAP）依赖 M8（需要先建立 QI 芯片通信）
