## 1. 先拍板：文档互相打架

这些不决，后面实现会对不上 SRS 验收。

### 1.1 识别类 DID

| DID | 文档 3（通用 CAN） | 文档 6（SRS） | 当前代码 |
| --- | --- | --- | --- |
| APP 软件版本 | `0xF189`（另有 `0xF195`） | **`0xF195`**（`0x2011` 已撤销） | APP：`0xF189`；Boot 另有 `0xF195` 等同 F189 |
| Bootloader 版本 | `0xF18D` | **`0xF180`**（SRS 写明 `0xF18D` 是 supportedFunctionalUnits） | `0xF18D` 固定字符串 `"1.0.0"` |
| 硬件版本 | `0xF191` | **`0xF193`** | `0xF191` |
| 序列号 | `0xF18C`（来自 Device Info） | `0xF18C` | `"N/A"`，不读 Flash |

**建议**：整车对接以 SRS 为准实现 `F195 / F18C / F180 / F193`；若仍要兼容文档 3，把 `F189/F18D/F191` 做成只读别名。文档 3、7 的 DID 表按此改一版。

### 1.2 版本 / SN 字符串长度

- 文档 3：`MAJOR.MINOR.PATCH`，含 `NUL` **≤ 16 字节**
- SRS 7.1：识别类 DID **定长 32 字节 ASCII 填充**
- 代码：16 字节 + `NUL`

**建议**：对外 SRS 用 32 字节填充；镜像头 `version[16]` 保持不变（那是 XATO 头，不是 DID）。

### 1.3 安全访问锁定时间

- 文档 3：锁定 **1～30 s**（供应商自定）
- 文档 8 / 代码：`SECURITY_LOCKOUT_MS = 60000`（60 s），超规范上限

**建议**：改为 30 s，三份文档与 `boot_safe_mode.c` 一起改。

### 1.4 功能寻址 CAN ID

- 文档 3 / 5：`0x18DB33F1`（SA=测试仪 `0xF1`）
- 代码过滤器：`CAN_ID_FUNCTIONAL_REQUEST = 0x18DB33D0`，匹配掩码 `0x18DB3300`

掩码能吃到 `F1`，常量名和文档示例不一致。建议常量改成 `0x18DB33F1`，文档写明「PF=DB、PS=33，SA 任意」。

### 1.5 APP 要不要实现 `0x27`

- 文档 3：所有外设 **SHALL** 实现 SecurityAccess
- 文档 7 / 当前 APP：`0x27` 固定 NRC `0x11`，用来判断「还在 APP」
- SRS：受保护写 / 例程要 Extended + Level 1

OTA 识别和充电配置锁冲突。**建议**：APP 实现 `0x27`（与 Boot 同一套 ECDSA）；主机判断在 APP 还是 Boot 改为读 DID（例如 `0xF180` 有值且 `0x2113` 为运行槽），不要再靠 `7F 27 11`。`zcanpro_ext_ota.py` 的 APP 探测逻辑一起改。

### 1.6 链接方式

- 文档 2 第八节仍给 `.sct` 示例，Boot 变更记录里还留着错误的 `0x00004000`
- 文档 7、9：只在 Keil Target 配 IROM，不用 scatter
- APP 工程：`umfTarg=1`，IROM `0x08005100 / 0xB700`，Scatter 空 — 符合 7/9
- **Boot 工程**：`IROM(0x08000000, 0x20000)`（整片 128 KB），`ScatterFile=.\Objects\bootloader.sct`

Boot 链接上限必须改成 **`0x08000000 / 0x5000`**，否则编大后会盖住 Slot A。文档 2 第八节改成「与 9 相同：Target IROM」，删掉过时 scatter 当规范。

### 1.7 文档 2 启动顺序

第六节仍是「先 Trial，再选槽」。源码 `main.c` 是 **先看 `ota_state==DOWNLOADING` 进 Safe Mode**，再 `process_trial_state`。按文档 7 改文档 2。

### 1.8 文档 8 私钥路径

仍写 `OTA simulator app/keys/private.pem`。应改为 `docs/keys/private.pem`。

## 8. 风险与依赖

1. **Boot IROM 未限 20 KB**：当前 bin 若小于 20 KB 则烧录碰巧没事；一旦 Boot 变大，产线 `merge_prod_bin` 仍按 20 KB 填充，溢出部分会被 Slot A 覆盖，现场变砖。B-1 应最先做。
2. **APP 无 SIT1145**：实验室 USB-CAN 直连 MCU 脚可能通，装 SIT1145 的板不通。A-1 与 OTA 真机验证绑定。
3. **霍尔 1 路 vs SRS 2 路**：不确认就做 `0x2118`，验收会对不上。
4. **APP 上 `0x27`**：改探测方式前不要先合脚本，否则 ZCANPRO 会把 APP 当成已在 Boot。
5. **文档 4 LEN 字段**：组帧前先用真实 Qi 芯片抓一包，避免按错 LEN。
