## 四、测试方法说明

### 4.1 硬件测试环境

| 设备 | 用途 |
|------|------|
| SWD 调试器 (J-Link / DAP-Link) | 烧录、断点、寄存器查看 |
| 示波器 / 逻辑分析仪 | GPIO 翻转周期测量、时序验证 |
| CAN 转接卡 | 模拟 CCU 发送 UDS 指令 |
| 万用表 | 电流/电压基本测量 |

### 4.2 软件测试方法

#### 方法一：GPIO 翻转 + 示波器（推荐）

```c
// 在回调中翻转 GPIO 用于示波器测量
volatile uint32_t cb_count = 0;
void test_callback(void)
{
  cb_count++;
  gpio_toggle(GPIOA, GPIO_PINS_0);  // PA0 翻转
}

// 在 main 中创建定时器
uint8_t tmr_test = timer_create(100, test_callback, 1);  // 100ms 周期
timer_start(tmr_test);
```

用示波器测量 PA0 波形，周期应为 200ms（100ms 翻转一次，高低各 100ms）。

#### 方法二：调试器断点 + 变量观察

1. Keil MDK 中设置断点在回调函数入口
2. 观察 `cb_count` 变量递增
3. 观察 `timer_get_tick()` 返回值

#### 方法三：串口打印（需 UART 驱动就绪）

```c
// 在主循环中定期打印状态
static uint32_t last_print = 0;
if (timer_get_tick() - last_print >= 1000)
{
  last_print = timer_get_tick();
  printf("tick=%lu, cb_count=%lu\n", timer_get_tick(), cb_count);
}
```

#### 方法四：IWDG 复位验证

```c
// 故意不喂狗，验证 IWDG 复位
// 记录复位次数到 RAM 变量（掉电丢失，仅用于快速验证）
volatile uint32_t reset_count __attribute__((section(".noinit")));

int main(void)
{
  reset_count++;  // 每次复位递增
  system_clock_config();
  timer_drv_init();
  wdg_drv_init();
  
  // 故意不喂狗：
  while(1)
  {
    timer_poll();
    // wdg_drv_refresh();  // 注释掉，约 1s 后复位
  }
}
```

### 4.3 预期测试结果汇总

| 测试项 | 预期指标 | 判定标准 |
|--------|---------|---------|
| SysTick 精度 | 1.000ms | ±0.1% (示波器测量) |
| 软件定时器精度 | period ± 1ms | 回调计数验证 |
| IWDG 超时 | ~1000ms | ±10% (不喂狗到复位时间) |
| 主循环周期 | < 1ms | timer_poll + wdg_refresh 耗时 |
| 16 定时器并发 | 全部正常 | 互不干扰 |
